# polyglot-playground

Rust, Python, C, C++ and more

## Commands

### Clean

```sh
make clean
make clean-rs
make clean-py
make clean-c
make clean-cpp
```

### Test

```sh
make test

make test-rs
make test-py
make test-c
make test-cpp

make test-rs playground/concepts/hello-world
make test-py playground/concepts/hello-world
make test-c playground/concepts/hello-world
make test-cpp playground/concepts/hello-world
```

### Format

```sh
make format-rs
make format-py
make format-c
make format-cpp
```

### Lint

```sh
make lint-rs
make lint-py
make lint-c
make lint-cpp
```
