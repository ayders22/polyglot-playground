# polyglot-playground

C, C++, Rust, Python and more

## Commands

### Clean

```sh
make clean
make clean-rs
make clean-py
make clean-c
make clean-cpp
```

### Test

```sh
make test
make test-rs
make test-py
make test-c
make test-cpp
```

### Format

```sh
make format-rs
make format-py
make format-c
make format-cpp
```

### Lint

```sh
make lint-rs
make lint-py
make lint-c
make lint-cpp
```
